Installation and Configuration of import records.

You need to map fields of Odoo with CSV & XLSX columns.

Select Model in which you want to import records : You need to select Odoo model in which you want to create records.

Search record from this value : Set Column Alphabet (From A-Z), from this value check existing record available or not. To avoid duplication of records in Odoo this must be needed.

Default value : During the import/export process, if you want to include specific values along with the processed data, you should enter these values in dictionary format.

Main Table : You need to enable this option if your configuration is main, for example if you want to add a sale order record then for the sale order model you need to create configuration record with main table enable & you need to create sale order line configuration separately without main table enable.

CSV file column name : You need to enter the Alphabet (From A-Z), for which CSV column you need to map the Odoo field.

Selected Model Fields : Select field of selected model in which you want to add value.

Field to search for M2O : This field is not required, if you choose Many2one field for mapping then you have an option to set the inner field of that Many2one model. It helps you to search records based on that field or else search with the name field of the Many2one model.

Sub Table : For One2Many field you have to select a sub table in which there is a separate configuration available for One2Many field/model. (In sub table there is the same concept to follow, the only difference is in that table you don’t need to enable Main table & also not required to enter Search record from this value, so it will create duplicate One2Many records from CSV & if you select then it will update existing record.)

This is sub table configuration.

Import CSV & XLSX file via SFTP.

Configuration of SFTP Connection.

Left Side : You need to enter SFTP details which are needed to connect to SFTP.

Store : You need to select the store and based on store some fields are visible below.

Dynamic Import Record : You need to select which Dynamic Import Record you want to connect with this SFTP record.

File Import Path : You need to enter file import path from SFTP.

Which type of data import? : You have to select which type of data you want to import: Inventory data or other data. If you select Inventory then you will see the location field. You have to enter the location where you want to change the inventory data.

Use first row as a header? : You need to select Use first row as a header? If you use Heading/Header in a CSV file.

Split the records of a file : If you have big files that need splliting for processing then you have to select the Split the Records of a File field as well.

CSV File Delimiter : At last, you have to enter the delimiter for the csv file (comma or semicolon).

This is the Schedule Action that will import the file from the SFTP path provided in configuration.

Import CSV & XLSX file via FTP.

Configuration of FTP Connection.

Configuration is same as SFTP connection.

This is the Schedule Action that will import the file from the FTP path provided in configuration.
